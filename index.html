LOGIC SIMULATOR

PHASE 1(Basic gates-AND,OR,NOT)

1.AND gate

An AND gate checks whether all its inputs are 1.

For a simple 2-input AND gate:


Input A = 0, Input B = 0 → Output = 0


Input A = 0, Input B = 1 → Output = 0


Input A = 1, Input B = 0 → Output = 0


Input A = 1, Input B = 1 → Output = 1


+
AND Gate Output = 0

2.OR gate

An OR gate checks whether any of its inputs are 1.

For a simple 2-input OR gate:


Input A = 0, Input B = 0 → Output = 0


Input A = 0, Input B = 1 → Output = 1


Input A = 1, Input B = 0 → Output = 1


Input A = 1, Input B = 1 → Output = 1


+
OR Gate Output = 0
